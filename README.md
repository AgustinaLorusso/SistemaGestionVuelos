# Sistema de Gestión de Vuelos

Aplicación desarrollada en Python para administrar vuelos, pasajeros y reservas mediante una interfaz de consola.

## Funcionalidades

- Alta de vuelos.
- Consulta de vuelos disponibles.
- Gestión de pasajeros.
- Reserva de vuelos.
- Validaciones de datos.
- Persistencia de información.
- Busqueda de vuelos con conexion si no hay existencia de vuelos directos

## Tecnologías

- Python
- Programación orientada a objetos
- Archivos txt
- Recursividad

## Conceptos aplicados

- Modularización del código.
- Manejo de excepciones.
- Estructuras de datos.
- Separación de responsabilidades.
